# سامانه آموزشی نوین فراهوش

فراهوش یک سامانه مدیریت مدرسه با رابط فارسی است. این مخزن شامل رابط وب، توابع سمت سرور Supabase، مهاجرت‌های پایگاه داده و سرویس مستقل کلاس آنلاین است.

## شروع سریع

- صفحه اصلی: `index.html`
- درگاه انتخاب نقش و ورود: `portal.html`
- مدیریت کلاس‌ها: `classroom/management.html`
- مدیریت و پرونده مشاوره: `counseling.html`
- گزارش‌های مدرسه: `reports.html`
- توابع سمت سرور: `supabase/functions/`
- تغییرات ساختار پایگاه داده: `supabase/migrations/`
- سرویس مستقل کلاس آنلاین: `server/` و `standalone-classroom/`

## معماری و توسعه

پیش از افزودن قابلیت یا تغییر ساختار، راهنمای [معماری و توسعه‌پذیری](docs/ARCHITECTURE.md) را بخوانید. برای انتشار نسخه‌های جدید در طول سال تحصیلی، مراحل [به‌روزرسانی و انتشار](docs/RELEASES.md) را دنبال کنید.

## اصول ضروری نگهداری

1. هر قابلیت جدید باید محدوده، نقش‌های مجاز، داده‌های مورد استفاده و معیار پذیرش مشخص داشته باشد.
2. تغییرات دیتابیس فقط با migration جدید و قابل بازبینی انجام شوند؛ migrationهای منتشرشده را بازنویسی نکنید.
3. کلیدهای محرمانه، رمزها، داده واقعی دانش‌آموزان و فایل‌های پشتیبان را وارد مخزن نکنید.
4. قبل از انتشار، تست‌های خودکار و بررسی دسترسی‌ها اجرا شوند.
5. تغییرات را در شاخه مستقل و از طریق Pull Request وارد `main` کنید.
6. قابلیت‌های سالم موجود را در حین توسعه ماژول‌های دیگر تغییر ندهید.

## وضعیت تست

Workflowهای GitHub Actions در مسیر `.github/workflows/` قرار دارند. تست‌های ساختار صفحات، تاریخ شمسی، نقش‌ها، گزارش‌ها و آزمون یکپارچه سرور در مسیر `tests/` هستند.

برای تست سرور مستقل، Node.js نسخه 20 یا بالاتر و PostgreSQL لازم است. دستورهای دقیق در `server/package.json` و workflow اعتبارسنجی ثبت شده‌اند.
